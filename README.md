# تطبيق الرفيق الذكي (Rafeeq Smart App) 📱🦯

تطبيق ذكي متكامل ومطوّر خصيصاً لمساعدة المكفوفين وضعاف البصر في الملاحة اليومية، التعرف على العوائق، وإدارة الحركة المستقلة بالكامل بدون الحاجة لاتصال بالإنترنت (**Offline-First Edge AI**).

---

## 🌟 الميزات الشاملة للتطبيق

* **🛡️ نظام التوجيه والتحذير المباشر في الشارع:**
  * **التوجيه الصوتي المستمر:** إرشادات صوتية لحظية ومتواصلة بدون انقطاع لتحديد المسار أثناء السير.
  * **كشف البرك والمياه:** التنبيه الفوري لتجمعات المياه والمستنقعات لمنع الانزلاق.
  * **كشف العوائق الشامل:** التنبيه الحركي والصوتي التلقائي للحفر، السيارات، الأشجار، الأعمدة، الحيوانات الضالة، ودرجات الرصيف.
  * **التنبيه التكتيكي المتعدد:** دمج التوجيه الصوتي مع اهتزازات متدرجة (Haptic Feedback) لتوضيح مدة وقرب العائق.
  * **وضع إدارة المكالمات:** التوقف التلقائي للتحذيرات أثناء استقبال المكالمات الهاتفية والتأمين الذاتي، مع العودة التلقائية فور انتهاء المكالمة.

* **💰 قارئ العملات الذكي:**
  * التعرف اللحظي بالصوت على الفئات المختلفة للعملات الورقية والبلاستيكية (المصرية) فور وضعها أمام الكاميرا.

* **🧭 التوجيه الداخلي والمفضلة والمسارات:**
  * **وضع الملاحة بالشارع والمسارات المفضلة:** تسجيل وتوجيه المستخدم في المسارات اليومية التكرارية والعودة إليها بسهولة.
  * **إدارة الأماكن والمواقع:** حفظ النقاط والمواقع المهمة والاسترشاد بها بدقة عبر المستشعرات.

* **🎙️ المساعد الصوتي والتوافقية الكاملة:**
  * **وضع المساعد الصوتي السريع:** استقبال وتنفيذ الأوامر الصوتية المستمرة بالضغط المطول.
  * **دعم إتاحة التكنولوجيا:** توافق كامل وبنية مجربة خصيصاً ليعمل بسلاسة مطلقة مع قارئ الشاشة (**TalkBack**).

---

## 🛠️ التقنيات والمكتبات المستخدمة (Tech Stack)

* **الإطار البرمجي:** Flutter (Dart)
* **معالجة الذكاء الاصطناعي محلياً:** TensorFlow Lite & Google ML Kit
* **الملاحة وأجهزة الاستشعار:** Camera, Geolocator, Accelerometer, Magnetometer, Flutter Compass
* **الصوت والاهتزاز:** Flutter TTS, Speech to Text, Vibration, Phone State Handler

---

## 🚀 طريقة البناء والتثبيت (CI/CD)

يتم بناء التطبيق وتوليد ملف **APK** تلقائياً عند كل تحديث عبر **GitHub Actions** باستعمال سيرفرات البناء المعتمدة على Flutter 3.19.x و Java 17.

> **مشروع تخرج / تطبيق خدمي ذكي دعمًا لإتاحة التكنولوجيا وتمكين المكفوفين.**
